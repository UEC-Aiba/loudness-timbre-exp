# ラウドネスと音色の実験アプリ（調整法）

標準音（純音）と同じ大きさに聞こえるように、比較音の大きさを調整する実験を行う、スマホ用の静的Webアプリです（`index.html` 1枚のみ、外部ライブラリなし）。実験は2種類あります：①音色・等ラウドネス曲線、②**帯域幅（臨界帯域幅）**。

## 公開URL
[公開](https://uec-aiba.github.io/loudness-timbre-exp/)

## 機能
- 標準音は、等ラウドネス曲線と同じ 1000 Hz の純音（固定）
- 比較する音色（純音・三角波・矩形波・ノコギリ波）と、比較音の基本周波数（220／440／880／1000／2000／4000 Hz）を、それぞれ複数選択できる（初期値：全音色・880 Hz）。どの比較音も、音圧（RMS）は標準音と等しく、これを 0 dB とする
  - 1000 Hz を選ぶと、標準音と同じ高さになり、純音が対照条件になる（音色の効果だけを取り出せる）
  - 純音だけを選び、周波数を複数選ぶと、自分の等ラウドネス曲線が描ける
- AとBが交互に鳴り、スライダー（数値は非表示）でBの大きさを調整して「同じ大きさ」に合わせる
- 開始位置は、等ラウドネス曲線から計算した予想値の ±9 dB。試行の順序はランダム。試行数は、音色の数 × 周波数の数 × 2回
- 結果画面：最初に「〇〇音は、純音より 〇 dB 小さい（大きい）音圧で、同じ大きさに聞こえた」というまとめを表示し、そのあと、条件ごとの調整量、純音との差、波形（2周期）とスペクトル、40 phon の曲線で重みづけした参考値を表示。純音を2つ以上の周波数で測った場合は、ISO 226（40 phon）と比較できる曲線も表示
- 結果をCSV形式でコピーできる（授業での集計用）


## 帯域幅の実験（臨界帯域幅より狭いか広いか）
- 画面の「実験の種類」で「帯域幅（臨界帯域幅）」を選ぶ（または `?mode=bandwidth`）。
- **標準音**：中心周波数の純音。**比較音**：同じ強さの4つの純音を、中心周波数のまわりに等間隔に並べたもの（幅 ΔF ＝ いちばん高い音といちばん低い音の周波数差。Zwicker, Flottorp & Stevens, 1957 の4つの純音の実験と同じ考え方）。比較音の音圧（RMS）は、標準音と等しく、これを 0 dB とする（4つの純音の合成の実効値が、標準音と一致することを確認済み：1秒の音で、差は 0.05 dB 以内）。
- ΔF（50／100／200／400／800／1600 Hz）と、中心周波数（500／1000／2000 Hz）を、それぞれ複数選択できる（初期値：ΔF は 50・100・200・400・1600 Hz、中心は 1000 Hz。10回・約 6 分）。
- 開始位置は、−4 dB（予想される範囲の中央）の ±9 dB。試行の順序はランダム。
- 結果画面：ΔF ごとの調整量のまとめ（臨界帯域幅より「狭い／広い」を併記）、**ΔF と調整量のグラフ（臨界帯域幅を点線で表示）**、狭い条件と広い条件の平均の差、条件ごとのスペクトル（臨界帯域をうすい色で表示）。
- 臨界帯域幅は、日本音響学会編「新版 音響用語辞典」の近似式（CB [Hz] ＝ 25 ＋ 75(1 ＋ 1.4 f²)^0.69、f は kHz）で計算する。目安：500 Hz で約 117 Hz、1000 Hz で約 162 Hz、2000 Hz で約 301 Hz。
- 予想される結果：ΔF が臨界帯域幅より狭い間は、約 0 dB。臨界帯域幅を超えると、マイナスが大きくなる（広帯域ほど、同じ音圧でも大きく聞こえる）。ISO 532-1 のモデル計算（純音が 60 dB SPL）では、中心 1000 Hz で、ΔF が 50／100／200／400／800／1600 Hz のとき、約 −0.1／−0.4／−1.3／−3.9／−7.6／−11.6 dB。中心 2000 Hz では、折れ曲がりが、ΔF の大きい側へ動く（200 Hz で約 −0.3、1600 Hz で約 −8.3 dB）。
- CSV：`center_Hz,deltaF_Hz,start,PSE_dB`

## 授業用のURL設定
公開URLの末尾に次を付けると、設定済みの状態で開く（学生が画面上で変更することもできる）。
- `?mode=contour`：純音のみ・6つの周波数（等ラウドネス曲線を描く。12回・約 7 分）
- `?mode=timbre`：全音色・1000 Hz（音色による大きさの違い。8回・約 5 分）
- `?mode=bandwidth`：帯域幅の実験（中心 1000 Hz、ΔF 50・100・200・400・1600 Hz。10回・約 6 分）
- `?bw=100,400&center=500,1000`：帯域幅の実験の自由な指定（ΔF は 50,100,200,400,800,1600、中心は 500,1000,2000 から）
- `?cond=pure,saw&f0=220,1000`：自由な指定（音色は `pure,tri,sq,saw`、周波数は 220,440,880,1000,2000,4000 から）

## 使用上の注意
- イヤホン（ヘッドホン）を推奨。結果は、再生機器の周波数特性にも影響される
- 標準音の音量は小さめに合わせ、実験中は端末の音量を変えない（比較音は、最大で標準音より約 30 dB 大きくなる）
- 「参考」の値は、40 phon の曲線による単純な重みづけで、帯域をまたぐラウドネスの加算を含まない。実際の大きさとは一致しない
- iPhone はマナーモードを解除し、Safari で開く
