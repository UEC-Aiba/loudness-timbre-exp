# loudness-timbre-exp# ラウドネスと音色の実験アプリ（調整法）

## 内容
- 標準音は、等ラウドネス曲線と同じ **1000 Hz の純音**（固定）
- **比較する音色**（純音・三角波・矩形波・ノコギリ波）と、**比較音の基本周波数**（220／440／880／1000／2000／4000 Hz）を、それぞれ複数選択できる（初期値：全音色・880 Hz）。どの比較音も音圧（RMS）は標準音と等しい（これを 0 dB とする）
  - 1000 Hz を選ぶと標準音と同じ高さになり、純音が対照条件になる（音色の効果だけを取り出せる）
  - 純音だけを選び、周波数を複数選ぶと、**自分の等ラウドネス曲線**が描ける
- AとBが交互に鳴り、学生がスライダーでBの大きさを調整して「同じ大きさ」に合わせる（調整法）。スライダーの数値は表示されない
- 開始位置は、予想される値（等ラウドネス曲線から計算）の ±9 dB（小さい方から／大きい方から）。試行の順序はランダム。試行数は（音色の数）×（周波数の数）×2回
- 結果画面：最初に「〇〇音は、純音より〇 dB 小さい（大きい）音圧で同じ大きさに聞こえた」というまとめを表示し、そのあと条件ごとの調整量（dB）、純音との差（＝音色の効果）、波形（2周期）とスペクトルの模式図、40 phon の曲線で重みづけした参考値を表示する。純音を2つ以上の周波数で測った場合は、ISO 226（40 phon）と比較できる曲線も出る
- 「結果をコピー」でCSV形式をコピーできる（授業での集計用）

## 注意
- イヤホン（ヘッドホン）を推奨。結果は再生機器の周波数特性にも影響される
- 実験の途中で端末の音量を変えない
- 標準音の音量は小さめに合わせる（最大で標準音より約30 dB大きい音が出る）
- iPhone はマナーモードを解除する
