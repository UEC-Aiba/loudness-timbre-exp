# ラウドネスと音色の実験アプリ（調整法）

1000 Hz の純音（標準音）と同じ大きさに聞こえるように、比較音の大きさを調整する実験を行う、スマホ用の静的Webアプリです（`index.html` 1枚のみ、外部ライブラリなし）。

## 公開URL
(https://uec-aiba.github.io/loudness-timbre-exp/)

## 機能
- 標準音は、等ラウドネス曲線と同じ 1000 Hz の純音（固定）
- 比較する音色（純音・三角波・矩形波・ノコギリ波）と、比較音の基本周波数（220／440／880／1000／2000／4000 Hz）を、それぞれ複数選択できる（初期値：全音色・880 Hz）。どの比較音も、音圧（RMS）は標準音と等しく、これを 0 dB とする
  - 1000 Hz を選ぶと、標準音と同じ高さになり、純音が対照条件になる（音色の効果だけを取り出せる）
  - 純音だけを選び、周波数を複数選ぶと、自分の等ラウドネス曲線が描ける
- AとBが交互に鳴り、スライダー（数値は非表示）でBの大きさを調整して「同じ大きさ」に合わせる
- 開始位置は、等ラウドネス曲線から計算した予想値の ±9 dB。試行の順序はランダム。試行数は、音色の数 × 周波数の数 × 2回
- 結果画面：最初に「〇〇音は、純音より 〇 dB 小さい（大きい）音圧で、同じ大きさに聞こえた」というまとめを表示し、そのあと、条件ごとの調整量、純音との差、波形（2周期）とスペクトル、40 phon の曲線で重みづけした参考値を表示。純音を2つ以上の周波数で測った場合は、ISO 226（40 phon）と比較できる曲線も表示
- 結果をCSV形式でコピーできる（授業での集計用）

## 授業用のURL設定
公開URLの末尾に次を付けると、設定済みの状態で開く（学生が画面上で変更することもできる）。
- `?mode=contour`：純音のみ・6つの周波数（等ラウドネス曲線を描く。12回・約 7 分）
- `?mode=timbre`：全音色・1000 Hz（音色による大きさの違い。8回・約 5 分）
- `?cond=pure,saw&f0=220,1000`：自由な指定（音色は `pure,tri,sq,saw`、周波数は 220,440,880,1000,2000,4000 から）

## 使用上の注意
- イヤホン（ヘッドホン）を推奨。結果は、再生機器の周波数特性にも影響される
- 標準音の音量は小さめに合わせ、実験中は端末の音量を変えない（比較音は、最大で標準音より約 30 dB 大きくなる）
- 「参考」の値は、40 phon の曲線による単純な重みづけで、帯域をまたぐラウドネスの加算を含まない。実際の大きさとは一致しない
- iPhone はマナーモードを解除し、Safari で開く
